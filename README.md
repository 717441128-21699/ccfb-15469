# 鼓点龙舟 · Dragon Boat Race

端午龙舟竞速游戏。玩家扮演**鼓手**，用鼓点决定整条船的桨频与同步；20 名划手按各自的反应速度、技术和体力跟拍入水，桨齐则船快，桨散则推力抵消、船身左右扭。

- 物理：TypeScript 固定步长 **120Hz**，6 条船 × 22 人同场
- 渲染：手写 **WebGL2**（无图形框架），俯视跟随镜头、波浪水面、船浪与河道
- 四大模块：队伍组建 / 节奏训练 / 比赛 / 赛后分析，localStorage 存档

## 操作

| 输入 | 作用 |
| --- | --- |
| `空格` / 鼠标点击 / 触屏 | 敲鼓（鼓点间隔即目标桨频 48–132 SPM） |
| `A` `D` 或 `←` `→` | 左舵 / 右舵 |
| `W` `S` 或 `↑` `↓` | 微调目标桨频 |

玩家船**只响应你敲出的鼓点**：不敲鼓，划手不会自己划。AI 船由各自鼓手按起航—巡航—冲刺三段节奏自动划。

npm install

## 核心物理模型

```
鼓点 → 划手反应延迟(均值+抖动+技术误差+疲劳迟滞) → 入水时刻
鼓手收拢：好鼓手按稳定性把全队反应延迟向统一锚点压缩（把二十个人练成一个人）
拉桨 F(t)=Fmax·力量·体力·sin(π·t/拉桨时长)（tick 内解析积分）
全队推力 = Σ桨力 × 同步效率 η
  η = exp(-(σ/0.12)²) 基础折减 + 0.12·exp(-(σ/0.045)²) 高同步协同增益
左右舷桨力差 → 艏摇力矩（船身扭偏）
船体：纵荡/横荡/艏摇三自由度，线性+二次水阻力、舵力、水流场、船浪互扰
体力：每桨按桨频与个体耐力消耗，后程反应变慢、发力下降
```

- **同步度决定船速**：入水时刻标准差 σ 越大，基础折减越多；σ 极小时触发协同增益（η 最高 1.12），鼓点稳的弱队也能靠齐桨战胜数值更强的对手。
- **船浪**：进入前方船 14m 锥形浪区会被横向推偏并产生附加阻力。
- **河道**：主流线摆动、湍流、局部逆流回水段；舵手可顺流走线。

## 验收指标（`npm test`）

1. **同步—速度指标**（`tests/sync.test.ts`）
   - 全队完全同步（σ≈0）时，仿真时间平均稳态速度与“推力减阻力”解析平衡速度偏差 **≤3%**（实测约 0.0x%）。
   - 入水离散度 σ 单调增大时，稳态速度严格单调下降。
2. **性能指标**（`tests/race.test.ts`）
   - 6 船 × 22 人全量物理单 tick 实测约 **10–14 µs**，相对 8.33ms 帧预算余量数百倍。
   - 整场 500m 比赛六船全部完赛、名次唯一、可种子复现。

## 目录结构

```
src/physics/  纯 TS 物理（可脱离 DOM 在 Node 测试）
  constants 物理常量与标定系数
  rng       带种子随机数（比赛可复现）
  paddler   划手状态机：等待入水→拉桨→回桨、体力
  drummer   AI 鼓手节奏规划 + 玩家鼓点
  boat      船体三自由度动力学、舵、船浪、解析平衡速度
  flow      水流场（摆动/湍流/逆流区）
  race      RaceWorld 编排、遥测、成绩
  teams     六支队伍 × 22 人个体数值
  rivers    三套河道
src/render/  WebGL2 渲染器、着色器、程序化网格
src/game/    主循环(固定步长+插值)、输入、音效、存档
src/ui/      菜单/组队/训练/HUD/赛后分析与 SVG 图表
tests/       Vitest 验收测试 + CDP 浏览器冒烟脚本
```

## 编好的队伍与河道

六支队（金鳞/橘颂/白鼍/飞鸢/号子/擂鼓）分四个实力档，每队 20 名划手有独立反应、技术、力量、耐力数值；三套河道（汨罗江静水、珠江后航道、嘉陵江急流）难度递增，含不同水流与逆流区。
